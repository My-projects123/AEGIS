Two-mic chain: NLMS adaptive canceller (REAL) subtracts the disturbance picked up by the reference mic, then the mode-aware Wiener stage and the TinyML mask clean the residual. The reference channel here is a SIMULATED second mic — the disturbance reaches it through a different synthetic path, so the filter has to learn that path exactly as it would on a headset. Last, a speech-only gate closes the channel when nobody is talking, so only the human voice is passed. The GRU's VAD head leads the decision; the DSP speech features can override it, but only when strongly confident, so a real talker the net does not recognise is never lost.
